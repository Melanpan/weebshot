# Keyboard shortcuts

Default bindings. Every one can be changed in *Options → Shortcuts*; the help inside Weebshot always shows your current ones.

### General

| Action | Shortcut |
| --- | --- |
| Open video | `Ctrl+O` |
| Close video | `Ctrl+W` |
| Quit | `Ctrl+Q` |
| Options | `Ctrl+,` |
| Documentation | `F1` |

### Playback

| Action | Shortcut |
| --- | --- |
| Play / pause | `Space` |
| Step back | `←` |
| Step forward | `→` |
| Step back (medium) | `Shift+←` |
| Step forward (medium) | `Shift+→` |
| Step back (long) | `Ctrl+←` |
| Step forward (long) | `Ctrl+→` |
| Previous subtitle line | `↑` |
| Next subtitle line | `↓` |
| Shuttle backwards (press again: faster) | `J` |
| Shuttle stop | `K` |
| Shuttle forwards (press again: faster) | `L` |
| Show/hide subtitles in the preview | `C` |

### Marking

| Action | Shortcut |
| --- | --- |
| Set In point | `I` |
| Set Out point | `O` |
| Mark current subtitle line as In/Out | `X` |
| Delete selected subtitle line | `Delete` |
| Clear In/Out | `Alt+X` |
| Go to In point | `Shift+I` |
| Go to Out point | `Shift+O` |
| Loop In→Out | `P` |

### Export

| Action | Shortcut |
| --- | --- |
| Screenshot | `S` |
| Screenshot without subtitles | `Ctrl+S` |
| Export clip | `E` |
| Save subtitles as… | `Alt+S` |

### General

| Action | Shortcut |
| --- | --- |
| Switch Inspector / Queue | `Ctrl+J` |
| Fullscreen | `F11` |

### Preview

| Action | Shortcut |
| --- | --- |
| Zoom preview in | `Ctrl+=` |
| Zoom preview out | `Ctrl+-` |
| Fit preview to window | `Ctrl+0` |

### Timeline

| Action | Shortcut |
| --- | --- |
| Timeline zoom in | `=` |
| Timeline zoom out | `-` |
| Timeline zoom to fit | `Shift+Z` |
